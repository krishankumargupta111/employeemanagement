# Employee Management System

A full-stack **Employee Management System** built using the MERN stack to simplify employee operations and management.

## 🚀 Features

- **Role-Based Authentication** – Separate Admin and Employee access.
- **Employee Management** – Manage employee records and profiles.
- **Attendance Management** – Track employee attendance.
- **Leave Management** – Apply for and manage leave requests.
- **Payslip Management** – Generate and manage employee payslips.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT

## ⚙️ Getting Started

Follow these instructions to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/krishankumargupta111/employeemanagement.git
cd employeemanagement
```

### 2. Start the Backend

```bash
cd backend
npm install
npm run dev
```

### 3. Start the Frontend

Open a new terminal and navigate to the frontend directory:

```bash
cd frontend
npm install
npm run dev
```
